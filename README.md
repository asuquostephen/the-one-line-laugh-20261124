# The One-Line Laugh — entry

Entry for the make.fun competition [The One-Line Laugh](https://make.fun/c/u-ronigrv-the-one-line-laugh-7ccca46f) (slug `u-ronigrv-the-one-line-laugh-7ccca46f`).

`main.py` (Python 3, standard library only) writes one funny line — a single sentence on any topic — to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`), verifying before it writes that the text is 1–200 characters and not only white space, and that the file round-trips byte-for-byte.

Run it:

    MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
    cat /tmp/out/entry.txt
